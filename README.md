# Xray Advanced 42 🚀

Современный, легковесный и устойчивый к цензуре установщик **Xray-core** (VLESS + Reality + xHTTP packet-up).

Проект сфокусирован на обходе современных систем DPI/ТСПУ за счет дробления трафика на уровне транспорта `xHTTP` и имитации легитимного HTTP/2 веб-трафика.
