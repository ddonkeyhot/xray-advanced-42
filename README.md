Готовое решение для быстрого развертывания устойчивого прокси-сервера (VPN) на базе ядра **Xray-core**. Идеально подходит для обхода современных систем глубокого анализа трафика (DPI), защищает реальный IP-адрес вашего сервера от сканирования и позволяет гибко управлять доступом.

---

## ✨ Ключевые возможности

1. **Максимальная маскировка (VLESS-Reality + xHTTP)**: Трафик мимикрирует под легитимные HTTPS-запросы к трастовым зарубежным ресурсам, доступ к которым открыт в РФ. Система использует настраиваемый пул SNI (доменов маскировки), позволяя выбирать хост индивидуально для каждого пользователя (или назначать случайно) и легко добавлять свои варианты. Использование xHTTP `packet-up` обеспечивает высокую производительность и устойчивость.
2. **Серверный Blackhole (Защита от РФ)**: Встроенные базы `Loyalsoldier/v2ray-rules-dat`. Любые запросы к сайтам зоны `.ru` или российским IP-адресам автоматически сбрасываются *внутри сервера*, предотвращая утечку IP-адреса VPS в системы мониторинга.
3. **Интеллектуальный Cloudflare WARP (Выборочно)**: Вы можете одним нажатием включить маршрутизацию трафика пользователя через Cloudflare WARP. Скрипт использует API Cloudflare для динамического получения персональных ключей и эндпоинтов, а также работает в безопасном режиме userspace (`kernelMode: false`), что гарантирует совместимость с любыми VPS и контейнерами. Это полностью скрывает IP вашего сервера от конечных сайтов.
4. **Интерактивный CLI / TUI**: Управление сервером осуществляется через удобные графические меню прямо в терминале. Никакого ручного редактирования JSON!
5. **Безопасность (Hardening)**: Дополнительный скрипт `secure.sh` автоматически защищает ваш VPS от брутфорс-атак и сканеров.

## 🛠 Установка

### Требования
* **ОС**: Чистый Ubuntu 20.04/22.04/24.04 или Debian 11/12.
* **Права**: `root` (или sudo).

### Шаг 1. Быстрая установка Xray
Выполните эту команду в терминале вашего сервера (она скачает и запустит мастер установки):

```bash
bash -c "$(curl -L https://raw.githubusercontent.com/ddonkeyhot/xray-advanced-42/main/install.sh)"
```

Мастер установки автоматически:
- Скачает актуальное ядро Xray-core.
- Сгенерирует надежные ключи Reality.
- Зарегистрирует аккаунт Cloudflare WARP.
- Установит утилиты управления.
- Предложит создать первого пользователя.

### Шаг 2. (Опционально, но рекомендуется) Защита сервера
Загрузите и запустите скрипт харденинга, чтобы защитить сервер:

```bash
bash -c "$(curl -L https://raw.githubusercontent.com/ddonkeyhot/xray-advanced-42/main/secure.sh)"
```
*Этот скрипт перенесет SSH на нестандартный порт (случайно сгенерированный или выбранный вами), отключит вход по паролю (оставив только ключи SSH), настроит фаервол (UFW) и включит защиту от подбора паролей (Fail2ban).*

## 💻 Управление и использование

Все утилиты управления устанавливаются глобально. Вы можете просто ввести в терминале:

```bash
xray
```
(или `xray_menu`)

Откроется главное меню со следующими разделами:

* **[1] Список пользователей (`userlist`)**: 
  - Просмотр всех созданных клиентов.
  - Показ VLESS-ссылки и **QR-кода** прямо в терминале.
  - Мгновенное включение/отключение Cloudflare WARP для конкретного человека.
  - Безопасное удаление пользователя.
* **[2] Создать пользователя (`newuser`)**: 
  - Мастер в 2 вопроса: Имя -> Нужен ли WARP.
  - Сразу выдает QR-код для подключения.
* **[3] Диагностика (`show_problems`)**: 
  - Дашборд здоровья сервера: проверка портов, фаервола, дат обновления баз GeoIP и журнал инцидентов.
* **[4] Обновить базы вручную (`xray_update_geoip`)**: 
  - Скачивание актуальных баз обхода блокировок. (По умолчанию скрипт уже создал задачу в Cron для автоматического обновления каждую неделю).
* **[5] Обновить систему (`xray_upgrade`)**: 
  - Проверка новых версий Xray-core на GitHub и безопасное обновление с созданием бэкапа настроек.

## 🔄 Обновление и Откат

**Если вы хотите обновить скрипты или ядро:**
Зайдите в `xray_menu` и выберите пункт `[5]`.
Либо запустите:
```bash
sudo install.sh --upgrade
```

**Если вы хотите полностью удалить Xray с сервера:**
Запустите установщик с флагом отката (потребуется подтверждение вводом слова RESTORE):
```bash
bash -c "$(curl -L https://raw.githubusercontent.com/ddonkeyhot/xray-advanced-42/main/install.sh)" --restore
```

**Если вы хотите откатить настройки безопасности (вернуть SSH на порт 22):**
```bash
bash -c "$(curl -L https://raw.githubusercontent.com/ddonkeyhot/xray-advanced-42/main/secure.sh)" --restore
```
